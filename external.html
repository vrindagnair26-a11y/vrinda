Root:The root node is the topmost node in the tree hierarchy. In other words,the root node is the one that doesn't have any parent. In the above structure, node numbered 1 is the rootnode of the tree. If a node is directly linked tosome other node, it would be called a parent-child relationship. Child node:If the node is a descendant of any node, then that node is said to be the parent of the sub-node. Sibling: The nodes that have the same parent are known as siblings.
